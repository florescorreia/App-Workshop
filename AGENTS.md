# App Workshop scope

This root repository contains IdeaFlow at `.` and independent future applications in `apps/<slug>/`. Preserve the root Git repository/remote and every existing application's source, environment, ports, accounts and volumes. Do not relocate IdeaFlow, create nested Git repositories, copy its business records into new apps, or alter another app as a side effect. Read each app's own AGENTS.md and docs/PRD.md before changing its domain. Shared build/test tools use containers and the detected Rancher Desktop Moby context explicitly. Each app has exactly three long-running services; transient tooling and systemd backup jobs are not additional app services. VPS apps use the secured host's existing rootless Podman/Quadlet and Caddy foundation with separate accounts, private bindings and storage. Consult docs/APP_WORKSHOP.md. Never publish secrets; never reset/prune other projects or volumes. Record actual checks and limitations.

# IdeaFlow implementation contract

Read docs/PRD.md before changing domain behavior. Exactly three long-running services: React/nginx frontend, FastAPI backend, PostgreSQL. Build and test with containers, using the detected Rancher Desktop Moby context explicitly. Preserve other projects, configuration and volumes; never use destructive resets.
