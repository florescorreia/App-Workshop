# App Workshop implementation contract

This repository hosts independent apps under apps/<slug> and shared VPS/workspace infrastructure at the root. Read the selected app's AGENTS.md and docs/PRD.md before changing domain behavior. IdeaFlow is the reference production app at apps/ideaflow; preserve its source, three-service architecture, PostgreSQL data/event protections, credentials and deployed identities. Never initialize nested Git repositories or share app volumes/accounts/passwords. Build/test using containers and the detected Rancher Desktop Moby context explicitly. VPS deployments retain the secured rootless Podman/Quadlet and host Caddy architecture. Keep app-specific source, docs, scripts, deployment assets and private backups in its app folder. Root docs/ contains shared hosting/security/workspace guidance only. Do not reset/prune existing projects or volumes. Do not commit secrets or import demo data automatically. Production changes require the user's deployment instruction; reading/checking production is permitted. Record checks actually run and limitations. See docs/APP_WORKSHOP.md.
