# VAVE design reference — 2026-10-15

Reference inspected: [Roland Berger Germany](https://www.rolandberger.com/de/), current public homepage. Private captured evidence is `artifacts/roland-berger-reference.png`, the HTML snapshot and computed-style capture. The observed page uses a black header, white/grey editorial panels, a blue hero, restrained red labels, strong black typography and square forms. Its computed font family is proprietary RBDesign Light/Bold.

IdeaFlow 1.2 applies that visual direction to its existing components: black sidebar and primary actions, white canvas, grey filter panels, thin rules, square controls, blue selection/focus accents and restrained red details. The VAVE sign-in message is “Less cost. Same function. Proven value.” VAVE programs and personal work lead the navigation; earlier IdeaFlow screens remain accessible in a disclosure.

The app keeps bundled Inter, existing accessible labels and visible keyboard focus. Fonts, images and runtime assets remain local. No proprietary corporate fonts, logo files or imagery are redistributed, and this treatment does not claim official Roland Berger brand certification. Desktop and mobile checks cover 1440×900, 1280×720 and 390×844. See [VERIFICATION.md](VERIFICATION.md) for actual results.
